Usage Rules

VariantWhen to use
PrimaryOne per screen. Main call-to-action: Save, Submit, Add Student.
SecondaryCancel, Go Back, alternative actions alongside primary.
OutlineSecondary importance but still branded — Export, View Details.
GhostToolbar / table row actions where visual weight must stay low.
DangerIrreversible actions only: Delete, Remove, Suspend.
LinkInline contextual actions within text or table cells.
