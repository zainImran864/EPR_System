Transitions

One token for the default interaction speed: --transition: 150ms ease. Use it for all hover, focus, and active state changes. Only go slower for structural animations (panel slides).

Default Token

--transition: 150ms ease;

Apply as: transition: background var(--transition), color var(--transition);

Structural Animation — Panel & Modal

Offcanvas panels slide in, modals fade in. These use 200–250ms with ease-out — slightly slower because the user watches the panel enter, not just a colour flip.

/* Offcanvas slide */
.offcanvas { transition: transform 220ms ease-out; }
.offcanvas.open { transform: translateX(0); }
.offcanvas.closed { transform: translateX(100%); }

/* Modal fade */
.modal-backdrop { transition: opacity 200ms ease; }
.modal-dialog { transition: transform 220ms ease-out, opacity 220ms ease; }

Easing Reference

DurationEasingUsed for
150ms easeSymmetric, snappyButton hover, nav item hover, badge, switch toggle, focus ring
200ms ease-outFast start, decelerateDropdown open, tooltip appear
220ms ease-outFast start, decelerateModal enter, offcanvas slide in
150ms ease-inSlow start, fast exitModal/offcanvas dismiss
0msInstantDisabled state change, error message appear (urgency)

Rules

  • Never animate width, height, or top/left — they trigger layout. Use transform and opacity instead.
  • Respect prefers-reduced-motion: wrap structural animations in a media query and fall back to instant.
  • Don't transition all — enumerate the properties to avoid animating unexpected things.
  • Keep UI animations under 300ms. Anything longer feels slow and blocks the user.
  • Loading spinners are the only continuous animation; everything else should end.
