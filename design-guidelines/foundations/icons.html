Inline SVG Pattern

<!-- Standard icon: 24×24 viewBox, 2px stroke, currentColor -->
<svg width="16" height="16"
     fill="none"
     stroke="currentColor"
     stroke-width="2"
     viewBox="0 0 24 24">
  <!-- path data -->
</svg>

<!-- Large empty-state icon: reduce stroke to 1.5 -->
<svg width="40" height="40" stroke-width="1.5" ...>

Usage Rules

RuleDetail
Always inline SVGNo icon fonts, no external sprites — inline keeps icons themeable and removes network requests.
Use currentColorNever hardcode fill/stroke hex values. Set color on the parent element.
Reduce stroke at large sizesUse stroke-width="1.5" for icons larger than 24px to maintain visual weight.
Don't scale with font-sizeSet explicit width and height attributes. Use flex-shrink: 0 in flex containers.
Add aria-label on standalone iconsIcons used as buttons need aria-label. Icons beside text labels are decorative — add aria-hidden="true".
Recommended libraryLucide Icons — MIT, consistent 24×24 stroke-based style, React/Vue/Svelte packages.
