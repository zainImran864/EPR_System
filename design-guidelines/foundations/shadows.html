Usage Rules

TokenValueUsed for
--shadow-sm1px blur, 5% opacityStat cards, table rows on hover, inline elements
--shadow-md6px blur, 7% opacityContent cards, popovers, floating labels
--shadow-lg15px blur, 8% opacityDropdowns, tooltips, notification panel

The sidebar has no shadow — it's a structural panel, not a floating element. The topbar uses only a bottom border, not a shadow.
